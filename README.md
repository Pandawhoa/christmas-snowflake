# 聖誕雪花賀卡

親手畫一片六角對稱的雪花，產生連結傳給親朋好友。對方點開就會看到寫實風的雪夜：月亮、雪山、針葉林、冒著炊煙的小木屋，聖誕老人的雪橇和奔跑的麋鹿從月亮前飛過；你的雪花會跳起來轉一圈，接著慢慢旋轉、閃閃發光，同時播放音樂盒版〈Jingle Bells〉。卡片上不放文字，祝福的話可以在 LINE 傳連結時一起寫。

- 整個網站只有一個 `index.html`（CSS、JS 都寫在裡面），不需要框架、不需要建置，也不載入任何外部 CDN。
- 卡片資料直接壓縮存在連結的 `#c=…` 裡，不需要資料庫，也不需要帳號。

## 使用方式

### 寄件人（做卡片）
1. 打開網頁（網址後面沒有 `#c=`），就會進入設計模式。
2. 用手指或滑鼠「引導」冰晶生長。不管手多抖、線多彎，程式只看起點、終點和大致方向，自動對齊成筆直的冰晶線條（角度一律是 30° 的倍數）。每一筆會轉成 6 個方向（純旋轉、不鏡射）：
   - **從中心往外畫**：長出一條主枝，對齊最近的主軸，長度看你畫多遠。
   - **從枝條上往外畫**：從線上最近的一點長出分枝，和母枝夾 ±60°、朝外。分枝上也可以再畫次分枝。順著枝條末端往外畫，就是把它延長。
   - **橫越主枝畫一筆**：在那個位置做出和主枝垂直的板邊；幅度夠大就直接變成完整的六角板。在枝條尖端附近橫畫或點一下，會加上六角小板。
   - **在空白處畫**：對齊到最近的主軸；太短或在空白處點一下則忽略。
   - 畫的時候會看到淡淡的手指筆跡，以及金色的「對齊後預覽」（6 個方向）。放開手指才正式加上。
   - **隨機生成**：模仿真實冰晶照片（Bentley／Libbrecht 的雪花結晶攝影）產生一片雪花，隨機選一種型態並變化參數：星狀樹枝晶、蕨狀樹枝晶、扇形板、星狀板（寬臂或臂尖六角小板）、六角板（內圈與肋線）。線條都是筆直的、角度都是 60° 的倍數；之後還可以繼續加筆畫。
   - **一鍵美化**：依真實結晶的邏輯加上互相平行、和主臂夾 60° 的細小側枝，臂尖加上六角小板，中心加小六角形，並加上光暈（再按一次取消）。
   - **復原**、**清除**（清除後也可以按「復原」找回）、**線條粗細**（細／中／粗）。
   - 筆畫會自動平滑，手不穩也沒關係。
3. 按「預覽卡片」可以看到對方收到時的樣子，按「返回編輯」回來繼續修改。
4. 按「產生連結・傳出去」（只要畫好雪花就能送出）後，可以：
   - 按「分享」（手機會跳出系統分享選單，可以選 LINE）；
   - 按「用 LINE 傳送」；
   - 按「複製連結」，再自己貼到聊天室。
5. 草稿會自動存在這台裝置的瀏覽器裡，關掉再打開也不會不見（瀏覽器禁止儲存時除外）。

### 收件人（看卡片）
- 點開連結就會直接看到雪花卡片。
- 瀏覽器規定網頁不能自動播放聲音，所以**第一次輕觸畫面時音樂才會開始**。右上角的喇叭圖示可以切換靜音。
- 手指滑過畫面，可以把背景的小雪花吹散。
- 下方的「我也做一片送人」會帶你進入設計模式。

## 部署到 GitHub Pages

1. 在 GitHub 建立一個 repository（例如 `snowflake-card`）。
2. 把 `index.html`（加上 `README.md`，可選）上傳到 repository 根目錄。
3. 到 **Settings → Pages**，Source 選擇 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等 1～2 分鐘後，網址會是 `https://你的帳號.github.io/snowflake-card/`。
5. 產生的卡片連結會長這樣：`https://你的帳號.github.io/snowflake-card/#c=…`

> 本專案用 `#`（hash）存放資料，因為 hash 不會被送到伺服器，GitHub Pages 與 LINE 也不會把它刪掉。程式也接受 `?c=…` 的寫法，以防萬一。

在本機測試：`python3 -m http.server`，然後打開 `http://localhost:8000/`。（直接雙擊 `index.html` 也能開；只是「複製連結」在 `file://` 下會改用備援的複製方式。）

## 連結長度（實測）

卡片只存雪花，不存文字，所以連結很短：

| 情境 | `#c=…` 長度 |
|---|---|
| 手繪引導 6 筆（主枝、2 分枝、六角板、尖端小板、次分枝） | 41 字元 |
| 隨機 3000 筆抖動筆畫的引導結果（每片 20 筆） | 約 60～110 字元 |
| 隨機結晶（1000 次）中位數／95%／最大 | 59／110／122 字元 |
| 　六角板／星狀板 | 約 30～45 字元 |
| 　扇形板 | 約 37～66 字元 |
| 　星狀樹枝晶／蕨狀樹枝晶 | 約 53～122 字元 |
| 舊式自由手繪線條（v3 連結，仍可編碼）中位數／最大 | 154／343 字元 |

完整網址＝你的網站網址（約 40 字）＋上表長度。

### 壓縮方式
- 目前格式 v4 有三種元素：
  - **手繪引導的直線段**：起點 9+9 bits、方向 4 bits（30° 的倍數）、長度 6 bits，一條約 4 bytes。
  - **六角形**：中心、半徑、方向，約 4.5 bytes。
  - **隨機結晶的折線**：只存 30° 扇形裡的線條，畫成 12 份；同粗細且相連的線段串成一筆，必要時原路折返。
- 整片雪花最多 220 點，超過時會自動再簡化（畫面上看到的就是送出去的樣子）。
- 最後加 1 byte CRC-8 檢查碼。連結被截斷或損壞時，會顯示友善的中文說明，並提供「我也做一片送人」按鈕。

### 舊版連結相容
目前產生的連結是格式 v4。舊連結都還能打開，畫面和當時一模一樣：
- v1：含收件人、祝福語、寄件人。打開後只顯示雪花，不顯示文字。
- v2：當時的線寬、12 份鏡射、舊版美化效果都保持原樣。
- v3：當時的自由手繪線條（6 份旋轉）照原樣顯示。

測試會用 `tests/fixtures-v1.json`、`fixtures-v2.json`、`fixtures-v3.json` 裡存的舊連結，逐點比對繪製結果。

## 之後想改成短網址（設定儲存介面）

在 `index.html` 最上方的 `<script>` 裡有：

```js
const CONFIG = {
  storage: null,
  ...
};
```

旁邊的註解附有範例。只要把 `storage` 改成一個物件，提供兩個非同步函式即可：

```js
CONFIG.storage = {
  async saveCard(data) { /* 把 data 字串存起來，回傳短代碼（A-Z a-z 0-9 - _，1～64 字） */ },
  async loadCard(code) { /* 用短代碼取回當初的 data 字串 */ }
};
```

- 設定之後，產生的連結會變成 `…/#s=短代碼`。
- `saveCard` 失敗時，會自動改用原本的 `#c=` 長連結，使用者不會被卡住。
- 舊的 `#c=` 連結仍然可以正常開啟。
- 可以用任何支援 JSON 的 key-value REST 服務，或是自己架設的小型 API（例如 Cloudflare Workers + KV）。請注意 API 金鑰不要寫在前端程式裡：前端拿到的金鑰任何人都看得到，應改用只能新增、不能刪除的公開端點。

## 測試

```bash
node tests/core.test.js        # 編碼／解碼、長度、損壞資料（純邏輯）
python3 tests/e2e.py           # 需要 playwright：pip install playwright && python -m playwright install chromium
```

`e2e.py` 會用 390×844 的觸控手機尺寸模擬畫線、隨機生成、復原、產生連結、開啟卡片（含舊版連結）、播放音樂、吹雪、損壞連結、離線操作。它也會在 iPhone SE、小 Android、橫向、平板、桌面等尺寸，檢查雪花（含光暈與開場跳躍的最高點）不會碰到標題或小木屋，並把截圖存到 `screenshots/`（`*-peak.png` 是跳躍最高點的畫面）。

## 已知限制

- **iPhone 靜音模式**：iOS 開啟側邊靜音開關時，網頁音效（Web Audio）可能沒有聲音，這是 iOS 系統的行為。
- **LINE 內建瀏覽器**：部分版本不支援系統分享選單（`navigator.share`），這時「分享」按鈕會自動隱藏，改用「用 LINE 傳送」或「複製連結」。剪貼簿權限也可能被限制，失敗時會提示「長按連結手動複製」。
- **連結預覽圖**：沒有設定 `og:image`（需要放在網站上的圖片絕對網址）。如果希望 LINE 聊天室顯示預覽圖，請自行放一張圖片並加上 `<meta property="og:image" content="https://…/preview.png">`。
- 「Merry Christmas」標題使用系統內建的草寫字體（iOS／macOS／Windows／Android 都有）。少數 Linux 電腦會改用一般襯線字體顯示。
- 背景全部用程式繪製（沒有載入任何圖片）。靜態部分只在開啟與旋轉螢幕時畫一次，之後每幀只畫動態元素。
- 手繪內容會被量化與簡化，非常細微的抖動會被平滑掉；這是為了讓連結夠短。
- 筆畫上限 63 筆；整片雪花上限 220 點（超過時會自動簡化）。
- 草稿使用 `localStorage`，無痕模式或部分 in-app 瀏覽器可能無法保存。
